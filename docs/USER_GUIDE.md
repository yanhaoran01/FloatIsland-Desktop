# FloatIsland 使用说明

## 启动与窗口

点击贴边胶囊或使用设置中的全局快捷键展开工作区。顶部导航进入对话、工具、音乐、阅读和下载。点击收起按钮返回胶囊；输入、结果与已访问子功能保留。临时菜单不会成为下次启动的恢复目标。

设置中的停靠选项控制顶部、左侧或右侧位置。窗口支持手动调整尺寸，尺寸会保存。小屏幕会按可用区域限制尺寸。独立工作区右上角提供最小化、最大化/还原和关闭；独立窗口关闭不会删除任务或历史。

快捷键可直接编辑，也可点击录入按钮后按组合键。Escape 结束录入。被其他应用占用的组合键会显示冲突，修改后重试。快捷键注册失败不会阻止首次开始使用。

“减少动画”保留静态表情，隐藏页面停止动画。角色采用原 SVG 引擎的表情与动作，不叠加自定义笑眼曲线或爱心；持续柔和跟随桌面鼠标，点击动作中也保持跟随；只改变目光方向，保留任务眼型。单击空闲角色依次轮换原生眨眼、睁大眼睛、注视、环绕、欢呼和掠过动作，忙碌时只眨眼回应并保留任务状态；动作中重复点击不会排队。按住移开、拖动、失焦或状态切换会取消手势，不会误展开胶囊。自动隐藏条点击后恢复可互动的小胶囊，点击胶囊空白区域或展开按钮才打开工作区；恢复入口和指针交互不会被被动全屏隐藏规则遮掉。

Agent 概览集中显示应用内 Codex、DeepSeek Harness，以及本机检测到的 Claude Code、WorkBuddy、Kimi Code、Gemini CLI、GLM、OpenClaw、Cursor、VS Code 和 Trae。卡片会标明程序或配置是否存在、任务是否运行或等待确认；历史记录会标成历史会话。支持切换到窗口的会话可从卡片返回对应程序；会话状态来自现有 Agent 活动扫描，检测到安装或配置本身不代表 Agent 正在运行。

## 对话

Codex 与 DeepSeek Harness 使用本机已有的程序、登录和模型配置。先选择项目文件夹并新建会话；概览页的刷新按钮可重新读取会话列表。程序不在常见安装目录时，可将环境变量 `FUSION_CODEX_EXECUTABLE` 或 `FUSION_DSH_EXECUTABLE` 设为对应可执行文件的绝对路径，随后重启 FloatIsland。

在模型设置中选择服务并填写连接信息。模型连接状态和刷新操作集中显示；输入框旁提供附件、发送或停止。语音识别生成草稿，确认后再发送。页面恢复不会自动开启麦克风。

语音输入独立于聊天服务，可用于 Codex、DeepSeek Harness 及其他聊天入口。Windows 上优先复用已安装的 DeepSeek Harness 本地 SenseVoice 识别程序和已缓存模型，无需聊天账号余额或额外语音 API Key；识别时按需启动本地进程，空闲后释放模型。首次使用需允许麦克风权限。如果本机尚无识别模型，可先在 DeepSeek Harness 中完成模型准备；已有原生语音连接也可作为备用。

在设置中维护服务地址、模型名称和凭据，选择可用连接后开始对话。连接错误时先核对地址、模型、凭据和网络，再重试。连接信息保存在本地配置中。

## 工具

工具页五类默认展开，搜索匹配名称、用途及子功能。进入工作区后，顶部按钮显示主要能力；参数较多的部分使用“更多设置”或明确命名的面板。返回目录后恢复搜索与位置。

| 类别 | 内容 |
| --- | --- |
| 常用 | 截图/OCR、收藏、剪贴板与模板、计算换算、二维码、抽签 |
| 媒体 | 网页、视频、录屏与媒体转换 |
| 效率 | 笔记待办提醒、计时、日期时区、翻译、应用与流程 |
| 文件 | 图片、PDF、ZIP、重命名、指纹与重复文件、局域网互传 |
| 开发 | 文本对比正则、JSON/CSV/编解码、颜色、密码/UUID、网络 |

### 截图与文字识别

区域、全屏和长截图使用实际系统捕获。也可导入图片。在预览区保存、识别文字、贴屏，或交给图片工具。识别结果可复制、保存并交给翻译。取消截图会显示中性状态，不作为处理失败。

默认 OCR 使用内置中文、英文模型，无需登录或联网下载模型。低分辨率、旋转文本、特殊字体和复杂背景会降低准确度，识别后应检查结果。

图片文字翻译输出译文文本，保留原图预览。文本翻译通过所选服务联网；云端原图排版翻译单独配置并遵循服务权限。两种结果形式不同。

### 二维码

“生成”页支持文本、网址和 Wi-Fi。输入区与预览并排；输入变化更新预览，PNG、SVG 导出和文本复制集中在预览下方。空 Wi-Fi 名称不会生成可导出的二维码。

“识别”页可选择图片、拖入图片、粘贴图片或截图识别。原图与识别结果并排，结果可复制和保存。过长内容或无法识别的图片显示具体错误。

### 图片、PDF、ZIP 与文件

图片编辑提供裁剪、旋转、标注、撤销、前后对比和导出；批量转换与压缩在同一工作区的对应子页。预览保持原比例，导出为新文件。

PDF 的页面处理、转换和历史通过顶部子功能进入。执行前核对页码、排序与输出设置。ZIP 工作区选择压缩或解压，导入后核对文件或包内条目，再执行；运行时提供真实进度和取消。

重命名先生成冲突预览，再执行；撤销依据持久操作记录。文件指纹支持算法选择、预期值比较与结果复制。重复文件的移除操作应先核对保留项。

专用文件工具接管自身拖放；不会把文件意外移动到收藏库。音乐和阅读的专用导入使用文件引用。收藏库仍按其既有移动入库规则处理拖入。

### 局域网互传

页面可见时启用接收服务，隐藏或收起后释放接收许可。点击发现设备，或填写局域网地址。选择文件或输入文本后点击目标设备发送。收到请求时核对文件清单并接受或拒绝。防火墙、隔离 Wi-Fi 或不同子网会影响发现；跨设备连通需在实际网络验证。

### 输入与结果串联

适用的结果提供复制、保存、预览或下一步操作，例如截图到 OCR、文字到翻译、图片到压缩、下载到阅读。交接复用产物引用，无需反复保存、导入。

## 音乐

固定子页为搜歌、歌单、本地音乐、正在播放和音源。

搜歌页选择音源后输入歌曲或歌手。音源未启用时可直接进入管理。播放、搜索、歌单和下载分别依赖源脚本的能力。

歌单分为发现歌单和我的歌单。首次打开自动加载所选平台的真实推荐歌单；切换分类会更新列表，也可输入关键词搜索。导入可粘贴分享链接或文本，先查看预览和异常项，再选择曲目。创建、导入与歌单更新遵循现有去重规则。

本地音乐支持多文件、文件夹扫描和拖入。默认引用原位置，不移动原文件。重新扫描更新已知文件；文件丢失时重新定位。导入任务会显示失败项。

播放和下载音质分别保存。自动、标准、高品质、无损和 Hi-Res 属于请求偏好，最终以音源返回文件的编码、采样率、位深和码率为准。MP3 转换属于有损处理，不能保留无损编码。

Internet Archive 和 Audius 默认加入“全部音源”搜索，也可以在来源下拉框中单独选择。Internet Archive 返回具有 Creative Commons 声明的音乐；Audius 返回开放播放的作品，作者未开放免费下载时会提示原因。来源状态分别记录，搜索成功不代表每首作品都提供无损或母带。

音源支持本地或 URL 导入、启停、首选和备用顺序。第三方脚本需自行导入，其兼容性取决于脚本版本与服务接口；更新后可重新验证。

发布包不内置 Apple Music 访问令牌，其专有歌词接口默认不可用；其他歌词来源按可用性回退。

收起时使用单行播放器，提供播放／暂停、静音、展开及关闭；歌曲进度在完整播放页调整。“正在播放”提供播放控制、进度与歌词。歌词跟随当前行，也可手动滚动查看。窄窗口会缩小封面并调整歌词区域；音量和音质设置独立保存。

## 阅读

书架、本地阅读、搜书和书源均有独立显名入口。书架提供最近阅读、搜索、排序和分组，继续阅读使用已保存位置。

文件与文件夹导入默认引用原文件。重复导入按文件身份去重；文件移动或授权失效后使用重新定位/重新选择，不创建虚假的有效引用。收藏库管理文件使用其独立的移动和撤销规则。

支持 EPUB、MOBI、AZW3、FB2、CBZ、TXT、PDF、Word 和 Excel。目录与定位由格式能力决定：PDF 使用页码与缩放，Excel 使用工作表；加密文件、DRM 和损坏文档可能无法打开。

正文页提供目录、查找、书签、备注、阅读设置和选中文字翻译。在正文中选择文字，点击“翻译选中文本”，译文显示在阅读器旁；窄窗口下显示在正文下方。可切换中文、英语、日语等目标语言，重新翻译、取消请求或复制译文。每次最多 5,000 个字符，翻译需要联网，关闭面板会取消未完成请求。保存的位置与标注属于文件或书籍身份；选择缓存的远程章节可离线读取，未缓存章节仍需联网。

书源管理支持 JSON、OPDS 和原站入口。维基文库及 Gutenberg 的公开目录与内容按来源协议获取。来源的搜索、正文、下载和网站浏览能力分别显示。

Z-Library 原站在未核验时不预填猜测地址。用户可编辑原站地址；网站登录发生在隔离浏览器会话中，应用不会把原站下载改为匿名 HTTP 请求。

## 下载

新建下载接受多行链接和分享文本。开始前核对识别结果与保存位置。媒体页分析链接后选择格式、列表、字幕和封面；BT/磁力页获取元数据并选择文件。任务与历史共用列表。

| 引擎 | 说明 |
| --- | --- |
| HTTP | 普通文件请求，续传取决于服务器 |
| 媒体 | yt-dlp 与 FFmpeg 处理下载及后处理，阶段以实际状态显示 |
| 原站 | Electron DownloadItem，使用网站会话与原始请求 |
| aria2 | 本机带鉴权 RPC，BT/磁力元数据和文件选择 |

按钮按任务当前能力显示。暂停不等于已具备跨会话续传；原站请求过期时需回网站重新获取。歌曲重试依赖音源重新解析。后处理阶段的控制能力与下载阶段不同。

未完成文件使用任务临时位置，完成后再校验和登记。取消只清理该任务所属未完成文件；重名不覆盖。阅读来源默认进入 Books，音乐来源进入 Music，普通任务沿用输出设置。BT 默认完成后停止做种，设置可调整。

网站登录、机器人验证、地区限制及 DRM 会影响下载。外部接口或元数据请求失败时，查看任务中的错误信息并重试；登录失效时返回原站重新登录。

## 设置

设置按连接、模型、角色、导航、提醒、工具和关于组织。窄窗口使用页面选择器，较宽窗口显示侧栏；切换设置项保留当前编辑上下文。

停靠位置与窗口快捷键位于导航设置。主题、角色外观和减少动画按个人偏好调整。需要麦克风、通知、录屏或局域网访问的功能，在使用时确认 Windows 权限；全局快捷键冲突需要改用其他组合。

工具设置影响对应工作区的默认行为。修改模型或服务连接后，回到相应页面检查连接状态。关于页提供版本与项目资料，反馈问题时使用这里显示的版本号。

## 数据、升级与排错

公开源码与 Release 不含用户配置、账号、聊天记录和文件授权。升级沿用内部应用标识与历史数据。安装版卸载默认不清理数据；手工删除配置前应自行备份。

| 现象 | 处理 |
| --- | --- |
| 快捷键冲突 | 在设置录入其他组合并重新保存 |
| 文件丢失或授权失效 | 使用重新选择/重新定位 |
| 在线搜索无结果 | 检查源启停与验证状态，确认服务是否可用 |
| 网站下载失败 | 回原站确认登录和链接有效期 |
| 本地 OCR 错字 | 使用更清晰图片，检查识别结果 |
| 模型连接失败 | 核对服务地址、模型、凭据和网络 |

提交问题时说明应用版本、Windows 版本、缩放比例、窗口尺寸、操作步骤及实际错误。不要公开凭据、私人文档、登录 Cookie 或完整个人配置。
